# รูปนักเตะ

วางไฟล์รูปที่ **คุณถือสิทธิ์ใช้งานเอง** ไว้ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ตาม `id` ของนักเตะใน `src/data/players.ts`

```
public/players/p001.gif   → นักเตะ id 'p001'  (การ์ดเคลื่อนไหว)
public/players/p002.png   → นักเตะ id 'p002'  (การ์ดภาพนิ่ง)
```

## เพิ่มนักเตะใหม่ (2 ขั้นตอน)

1. วางไฟล์รูปในโฟลเดอร์นี้ เช่น `p036.gif`
2. เพิ่มหนึ่งบรรทัดใน `src/data/roster.ts` — `{ file: 'p036', rarity: 'epic' },`

ชื่อ ตำแหน่ง OVR และค่าพลัง 6 ด้าน ระบบคำนวณให้เองจากเลขท้าย id (ค่าคงที่ ไม่สุ่มใหม่ทุกครั้ง)
อยากกำหนดค่าไหนเองก็ใส่ทับได้ เช่น `{ file: 'p036.gif', rarity: 'legendary', position: 'ST', ovr: 94 }`

เพิ่มรูปทีละหลายใบ ให้รัน `python3 tools/scan-players.py` จะพิมพ์บรรทัดของไฟล์ที่ยังไม่มีในระบบให้ก๊อปวาง

## นามสกุลไฟล์ที่รองรับ

`.png` · `.gif` · `.webp` · `.jpg` — ปนกันในโฟลเดอร์เดียวได้ ไม่ต้องแก้โค้ดหรือประกาศอะไรเพิ่ม
ระบบจะไล่ลองนามสกุลตามลำดับใน `PORTRAIT_EXTENSIONS` (`src/data/players.ts`) จนกว่าจะเจอไฟล์จริง
แล้วจำผลไว้ ทำให้การ์ดใบอื่นของนักเตะคนเดียวกันโหลดตรงนามสกุลทันที

- **.gif เคลื่อนไหวได้เต็มรูปแบบ** วนลูปเองตามที่ไฟล์กำหนด (ถ้าอยากให้เล่นรอบเดียวให้ export gif แบบ loop 1 ครั้ง)
- ถ้าไฟล์ส่วนใหญ่ในโปรเจกต์เป็น `.gif` ให้สลับ `'gif'` ขึ้นมาเป็นตัวแรกใน `PORTRAIT_EXTENSIONS` จะโหลดไวขึ้น
- gif ขนาดใหญ่กินแรมพอสมควร แนะนำไม่เกิน ~1 MB ต่อใบ และกว้างไม่เกิน 512 px

- ระบบแสดงรูปเต็มใบโดยไม่ครอบกรอบและไม่ซ้อนข้อความใด ๆ ตัวรูปจึงควรมีข้อมูลการ์ดครบในตัว (OVR, ตำแหน่ง, ชื่อ)
- ขนาดที่แนะนำ: 256×256 หรือ 512×512 px, PNG พื้นหลังโปร่ง (สัดส่วนอื่นก็ได้ ความสูงปรับตามไฟล์อัตโนมัติ)
- ตอนนี้ในโฟลเดอร์มีรูปตัวอย่างที่สร้างจาก `tools/generate-cards.py` อยู่แล้ว (สร้างใหม่ได้ด้วย `python3 tools/generate-cards.py`)
- ทับไฟล์เดิมได้เลยเมื่อมีรูปจริง ระบบไม่ต้องแก้อะไร
- ถ้าไม่มีไฟล์ตรงกับ id การ์ดจะ fallback เป็นกล่องข้อมูลย่อโดยอัตโนมัติ
- ถ้าอยากชี้ไปที่ URL อื่น ให้ใส่ `imageUrl` ในข้อมูลนักเตะ ค่านี้จะชนะ path นี้เสมอ

หมายเหตุเรื่องสิทธิ์: รูปนักเตะจริง โลโก้สโมสร และกรอบการ์ดจากเกมอื่นเป็นทรัพย์สินทางปัญญาของเจ้าของเกมและตัวนักเตะ
ไม่ควรนำมาใช้ในโปรเจกต์นี้ ให้ใช้ภาพที่ถ่าย/สร้าง/ซื้อสิทธิ์เอง หรือใช้ fallback ที่ระบบมีให้
