# ไอคอนรางวัลกลางของเกม

ไฟล์ในโฟลเดอร์นี้ถูกใช้เป็น **รูปตั้งต้น** ของรางวัลแต่ละประเภท
ทั้งใน FC ALLSTAR PASS และกล่องสุ่ม Lucky Box โดยที่แอดมินไม่ต้องไปใส่รูปทีละช่อง

| ไฟล์ | พาธที่ใช้ | ใช้กับรางวัลประเภท |
| --- | --- | --- |
| `money.png` | `/icons/money.png` | เหรียญ (coins) |
| `exchange-point.png` | `/icons/exchange-point.png` | แต้มแลกนักเตะ (EP) |
| `upgrade-point.png` | `/icons/upgrade-point.png` | แต้มตีบวก (UP) |
| `exp-ticket.png` | `/icons/exp-ticket.png` | ตั๋วพาส |
| `boost-100.png` | `/icons/boost-100.png` | ยังไม่ผูกอัตโนมัติ — ใส่พาธเองได้ที่ช่องไหนก็ได้ |

ลำดับที่ระบบเลือกรูปมาแสดงคือ **รูปที่แอดมินใส่เองในช่องนั้น → รูปตั้งต้นตามตารางนี้ → ไอคอนอีโมจิ**
ช่องไหนอยากให้ต่างจากปกติค่อยไปใส่รูปเองเป็นช่อง ๆ ไป

## เปลี่ยนรูปตั้งต้น

ทับไฟล์ชื่อเดิมในโฟลเดอร์นี้แล้ว commit — ไม่ต้องแก้โค้ดหรือค่าตั้งใด ๆ
ถ้าเบราว์เซอร์ยังโชว์รูปเก่าจากแคช ให้ตั้งชื่อไฟล์ใหม่แล้วแก้พาธใน
`DEFAULT_REWARD_IMAGE` (src/services/pass.ts) กับ `DEFAULT_CELL_IMAGE` (src/services/luckyGrid.ts)

## เพิ่มไอคอนใหม่

วางไฟล์ `.png` `.webp` `.gif` `.jpg` ไว้ในโฟลเดอร์นี้ แล้วใส่พาธ `/icons/<ชื่อไฟล์>`
ในช่อง "รูปของรางวัลชิ้นนี้" ของหน้า ADMIN ได้เลย

รูปในโฟลเดอร์นี้ถูกเสิร์ฟตรงจากเว็บ **ไม่กินพื้นที่เอกสารค่าตั้ง** ซึ่งจำกัดที่ 1 MB
ต่างจากการกดปุ่ม "อัปโหลดรูป" ที่ฝังไฟล์ลงไปในค่าตั้งเลย

ขนาดที่เตรียมไว้: ด้านยาวสุด 160px พื้นหลังโปร่งใส ไฟล์ละราว 25–40 KB
