# ฝั่งเซิร์ฟเวอร์ของ APEX ELEVEN

โฟลเดอร์นี้คือ Cloud Functions ที่ทำหน้าที่ **ตัดสินผลแมตช์และแจกดาวแทนเครื่องผู้เล่น**

## ทำไมต้องมี

เดิมเครื่องผู้เล่นเป็นคนสุ่มผลแมตช์แล้วเขียนดาวลงฐานข้อมูลเอง ใครเปิด DevTools
ก็ยัดดาวได้ตามใจ กฎ Firestore ทำได้แค่ "จำกัดความเร็ว" ไม่ใช่ "ห้าม"

พอย้ายมาที่นี่ เครื่องผู้เล่นทำได้อย่างเดียวคือ *ขอลงแข่งหนึ่งนัด* —
เซิร์ฟเวอร์เป็นคนอ่านคลังการ์ดจริง คำนวณค่าพลังทีมเอง สุ่มผลเอง แล้วบวกดาวเอง
ตัวเลขที่เครื่องผู้เล่นส่งมาไม่มีผลกับแพ้ชนะเลยแม้แต่ตัวเดียว

## ใช้กติกาชุดเดียวกับหน้าเว็บ

ไม่ได้ก๊อปกติกามาไว้อีกชุด — `tsconfig.json` ตั้ง path `@/*` ชี้ไปที่ `../src`
ฟังก์ชันจึง `import` `simulateMatch`, `calculateTeamRating` ฯลฯ จากไฟล์เดียวกับที่หน้าเว็บใช้
แก้สมดุลที่เดียวแล้วตรงกันทั้งสองฝั่งเสมอ

## ต้องอัปเป็นแพลน Blaze ก่อน

Cloud Functions ใช้กับแพลน Spark (ฟรี) ไม่ได้ ต้องผูกบัตรเปลี่ยนเป็น **Blaze**
แต่โควตาฟรีต่อเดือนยังอยู่ (2 ล้านครั้ง) — เกมขนาด 250 คนเล่นกันหนัก ๆ
ก็ยังไม่ถึงโควตาฟรี ตั้ง `maxInstances: 10` ไว้ในโค้ดแล้วเพื่อกันค่าใช้จ่ายบานปลาย

แนะนำให้ตั้งงบเตือนไว้ด้วย: Firebase Console → ⚙️ Usage and billing → Budgets & alerts

## คำสั่ง

```bash
cd functions
npm install          # ครั้งแรกครั้งเดียว
npm run build        # คอมไพล์ TypeScript → lib/
npm run deploy       # ขึ้นเซิร์ฟเวอร์จริง
npm run logs         # ดู log ย้อนหลัง
```

deploy ครั้งแรกจะถามให้เปิด API หลายตัว ตอบ yes ไปได้เลย ใช้เวลาราว 2–3 นาที

## ฟังก์ชันที่มีตอนนี้

| ชื่อ | หน้าที่ |
|---|---|
| `ping` | เช็คว่า deploy สำเร็จและหน้าเว็บเรียกได้จริง |
| `playMatch` | ตัดสินผลแมตช์หนึ่งนัดและบวกดาว |

### ด่านที่ `playMatch` ตรวจก่อนให้ดาว
1. ล็อกอินจริง (`request.auth`)
2. จัดตัวครบ 11 คน โดยการ์ดทุกใบต้องมีอยู่จริงในคลัง
3. คูลดาวน์ 15 วินาทีต่อนัด — ยิงถี่กว่านี้ถูกปฏิเสธ
4. คูลดาวน์ 30 นาทีต่อคู่แข่งคนเดิม — กันนัดกันผลัดแพ้ชนะปั้มดาว
5. ท้าตัวเองไม่ได้

ค่าพลังทีมคำนวณจาก `accounts/{uid}.state` บนเซิร์ฟเวอร์เสมอ ไม่รับตัวเลขจากเครื่องผู้เล่น

## ยังไม่เสร็จ — ต้องทำต่อก่อนถึงจะกันได้จริง

ตอนนี้ฟังก์ชันพร้อมใช้แล้ว แต่ **ยังไม่มีอะไรบังคับให้เครื่องผู้เล่นต้องใช้มัน**
ต้องทำอีก 3 อย่างถึงจะปิดช่องได้จริง (ดูรายละเอียดใน UPDATE-NOTES.md):

1. `syncLeague` — ย้ายการคิดรอบลีกประจำวันมาที่เซิร์ฟเวอร์ (ตอนนี้ลีกยังแจกดาวเองที่เครื่องผู้เล่น)
2. ต่อสายหน้าเว็บให้เรียก `playMatch` แทนการสุ่มผลเอง
3. ล็อกใน `firestore.rules` ไม่ให้เครื่องผู้เล่นแก้ดาวได้เลย

**อย่าเพิ่งล็อกกฎก่อนทำข้อ 1–2 ให้เสร็จ** — ลีกจะเขียนเซฟไม่ผ่านแล้วเกมพัง
