# Football Web Game

เกมฟุตบอลบนเว็บ (React + TypeScript + Vite + Tailwind CSS)

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

## เล่นออนไลน์ (Firebase + Vercel)

ใส่ค่า Firebase ลงไฟล์ `.env` แล้วเกมจะเปลี่ยนเป็นโหมดออนไลน์เอง: บัญชีอยู่บนคลาวด์
เล่นต่อได้ทุกเครื่อง ตารางอันดับเป็นผู้เล่นจริง และระบบจับคู่ดึงทีมของผู้เล่นจริงมาเป็นคู่แข่ง

ขั้นตอนละเอียด (ตั้งค่า Firebase, ขึ้น Vercel, แก้ปัญหาที่เจอบ่อย): ดู **[DEPLOY-ONLINE.md](./DEPLOY-ONLINE.md)**

ไม่ใส่ `.env` ก็ยังเล่นได้ตามปกติ แต่เป็นโหมดออฟไลน์ (เก็บข้อมูลในเครื่องเหมือนเดิม)

## สถานะปัจจุบัน

ใช้งานได้แล้ว: หน้า MY TEAM (สนาม perspective + จัดทีมด้วยลากวางและคลิกสลับ), คลังการ์ด, ภารกิจ, เปิดซองการ์ดจริง, Team OVR/Chemistry/มูลค่าทีมคำนวณสด, ระบบบัญชี/เซฟถาวร, ตารางอันดับและจับคู่กับผู้เล่นจริง
ยังไม่ทำ: Transfer Market, การแข่งแบบสองฝ่ายชนกันสด ๆ (ตอนนี้จำลองผลจากทีมล่าสุดของคู่แข่ง)

หน้า Squad Builder ถูกยุบเข้าหน้า MY TEAM แล้ว

## กฎของโปรเจกต์

- โครงสร้างโฟลเดอร์ใน `src/` ถูกล็อกไว้แล้ว ห้ามย้าย/เปลี่ยน architecture โดยไม่จำเป็น
- `types/` = สัญญากลางของข้อมูล ถ้าจะเพิ่มระบบใหม่ ให้เพิ่ม type ก่อน
- `data/` = mock data เท่านั้น (ยังใช้เป็นตัวสำรองเมื่อเซิร์ฟเวอร์ยังไม่มีผู้เล่นพอ)
- `services/firebase/` = ชั้นที่คุยกับคลาวด์ที่เดียว ส่วนอื่นของแอปไม่ต้องรู้จัก Firebase
- `services/` = logic บริสุทธิ์ (pure function) ห้าม import React
- `hooks/` = ตัวเชื่อมระหว่าง services/data กับ UI
- `components/` = UI ที่ใช้ซ้ำ, `pages/` = ประกอบ component เป็นหน้าจอ

## Alias

`@/` ชี้ไปที่ `src/` เช่น `import type { Player } from '@/types/player'`
